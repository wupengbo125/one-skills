# Query the Markdown Wiki

Answer questions from the compiled personal Wiki.

1. Read `onewiki/index.md`, then the smallest set of linked topic and canonical pages needed for the question.
2. Follow semantic links when the answer spans related subjects, projects, people, workflows, decisions, or evidence.
3. Answer only from `onewiki/`. Do not inspect `raw/`, external sources, or unsupported files.
4. Cite relevant Wiki paths and distinguish confirmed, source-backed, contested, and watchlist knowledge when those labels matter.
5. If the answer is absent, say so and recommend `ingest`; do not fill the gap from assumptions.
6. Do not modify or move files. If an answer is worth preserving, recommend saving it as a Markdown source under `raw/` and running `ingest`.

Completion means the answer is concise, traceable to canonical Wiki pages, and honest about missing or conflicting knowledge.
