# 笔记记录 (note)

向远端 `raw/` 写入或更新源材料（直接写远端：豆包用 MCP，其他环境用 `gh api`；写入即提交，无本地文件，流程见 SKILL.md）。



## 1. 记到大本子（一句话清单/条目）→ **条目模式**：

1. 统一写入远端 `raw/misc/大本子.md`（豆包用 MCP `create_or_update_file`，其他环境用 `gh api` PUT；已在子目录，ingest 不移动，路径稳定），**不新建文件、不预设分类**
2. 文件内按 `## 小节` 自然分类，判断内容属于哪个小节（如"集会"、"电影"、"宠物"），有则追加到该小节下一条 `-` ，无则新建 `## 小节` 再追加

## 2. 记笔记 / 存资料（文档模式）

1. **命名落盘**：写入远端 raw 根目录（豆包 MCP `create_or_update_file`，其他环境 `gh api` PUT），不准分类，如： `raw/<YYYY-MM-DD>-<简短slug>.md`，保留用户原文或关键资料。
2. **极简反馈**：反馈落盘路径。

## 3. 更新已有文档

1. **检索定位**：先调用 `python3 scripts/wiki.py search "<关键词>"` 定位目标文档。
2. **确认修改**：说明拟改动内容，确认后精准更新。
3. **提交**：写入远端即自动 commit+push（豆包 MCP 或 `gh api`，见 SKILL.md），无需本地 git。如需更新本地检索索引，再执行 `python3 scripts/wiki.py sync "<相对路径>"`。
