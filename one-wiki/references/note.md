# 笔记记录 (note)

向 `raw/` 写入或更新源材料。

## 长度判断（自动路由）

记笔记前先判断内容长度，**不需要用户指定**：

- **≤50 字**（一句话清单/条目）→ **条目模式**：
  1. 判断内容类别（影视/美食/读书/技术…）
  2. 检索定位已有同类清单文档（如 `onewiki/lists/待看电影.md`），无则新建
  3. 文档内按 `## 小节` 分类（如 `## 科幻`、`## 悬疑`），有对应小节则追加到该小节下一条 `- `，无则新建 `## 小节` 再追加
  4. 不新建独立文档
- **>30 字**（文章/详细笔记）→ **文档模式**：按下方流程新建一篇文档。

## 1. 记新笔记 / 存资料（文档模式）

1. **命名落盘**：写入 `raw/<YYYY-MM-DD>-<简短slug>.md`，保留用户原文或关键资料。
2. **提交 git**：提交本地 commit。
3. **极简反馈**：反馈落盘路径。

## 2. 总结当前会话

1. **提炼预览**：整理核心背景、决策、代码/配置改动及 TODO，终端输出供用户确认。
2. **落盘保存**：确认后写入 `raw/<YYYY-MM-DD>-<简短slug>.md`。
3. **提交 git**：提交本地 commit。

## 3. 更新已有文档

1. **检索定位**：先调用 `python3 scripts/wiki.py search "<关键词>"` 定位目标文档。
2. **确认修改**：说明拟改动内容，确认后精准更新。
3. **同步索引**：执行 `python3 scripts/wiki.py sync "<相对路径>"` 并提交本地 git。
