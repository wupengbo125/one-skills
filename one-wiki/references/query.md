# 知识查询 (query)

从已编译的 `onewiki/` 中回答问题并追溯出处。

仓库在 `~/onespace/github/one-llmwiki/`，两棵树：

```
raw/       原始笔记（原料）    <YYYY-MM-DD>-<slug>.md、misc/大本子.md、<域>/
onewiki/   编译后的知识（查这里）  index.md 总索引、<域>/index.md 领域索引
```

## 意图分流：先选手段

「最近」「有哪些」「哪一类」这类问句里没有可搜的内容词，索引里搜不到；先按下表挑手段。

| 问法 | 手段 |
| :--- | :--- |
| 某个词、某句话是怎么说的（人名、术语、原话） | `python3 scripts/fts.py search "<关键词>"` |
| 某个领域、某一类里都有什么（"有没有…相关的"） | 从索引进：总索引 `onewiki/index.md`、领域索引 `onewiki/<域>/index.md`，顺双链下钻 |
| 最近、最新、时间 | 列目录按时间倒序：`ls -t raw/`（文件名带 `YYYY-MM-DD`） |

**完成标准**：一条路走空就换下一条，三条都走完才算查完；回答里说清走了哪几条。

## 执行步骤

1. **定位**：按意图分流选出的手段定位相关概念与实体。
2. **查阅双链上下文**：直接阅读命中页面，沿 Obsidian 双链追溯完整逻辑。
3. **精准回答与引用**：基于 `onewiki/` 内容合成回答，并标明引用的 Wiki 页面。
4. **优质结论沉淀**：若解答产生高价值新结论，建议用户通过 `note` 存入 `raw/` 待后续编译。
