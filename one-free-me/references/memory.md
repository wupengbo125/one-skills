# 记忆沉淀指南

## 触发时机

- **自动伴随**：推进中产生实质代码/配置修改或关键决策时；
- **手动收工**：用户输入“收工”或“解脱我”时。

## 执行步骤

1. **价值判定**：无实质增量则不记录（手动触发时直接回复已完成）。
2. **写情景长文**：写入/追加至 `memory/<YYYY-MM>/<YYYY-MM-DD_中文主题>.md`，记录背景、改动脉络、资产与避坑。
3. **记流水大纲**：向 `memory/<YYYY-MM>/index.md` 追加指针：`- YYYY-MM-DD HH:MM：[中文主题](<YYYY-MM-DD_中文主题>.md) - 简述`。
4. **画像更新**：获知用户身份、习惯或喜好时，顺手更新 `system/profile.md`。
5. **同步索引**：`python3 scripts/free_me.py sync "<改动的文件路径>"`。
6. **提交 git**。
7. **极简反馈**：手动触发时一句话回复结果。
