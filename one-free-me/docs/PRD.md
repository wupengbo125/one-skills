# One Free-Me 记忆中枢与执行代理需求文档

## 1. 核心设计原则 (Core Principles)

1. **数据与能力分立**：记忆数据、文档与画像统一保存在 `$github_dir/one-hippocampus/` 数据仓；检索、索引同步与近期记忆治理等工具集中在 `one-free-me/scripts/free_me.py` 辅助脚本中。
2. **双轨沉淀机制**：区隔“自动记忆（伴随增量）”与“收工记忆（情景复盘）”两条主线，按需沉淀。
3. **意图驱动触发**：仅支持编码过程自动伴随记录，以及用户显式输入的收工意图（“收工”、“超级我”）。日常记笔记存资料归属于个人知识库（`one-take-notes`）。
4. **全中文文章命名**：系统顶层骨架采用英文标准目录，所有具体文章与文档统一采用中文命名。
5. **分立数据层拓扑**：包含 `system/`（系统画像与配置）、`memory/`（单层扁平情景记忆）与 `onewiki/`（领域分类实操规程）。
6. **本地全文检索**：文档入库后由辅助脚本同步更新本地 SQLite FTS5 数据库（`.fts.db`，由 `.gitignore` 忽略），提供毫秒级 BM25 全文检索。
7. **近期记忆置顶与双阈值治理**：`recent.md` 记录近期活跃流水，条目访问或更新时刷新时间戳并置顶到表格首行，按 60 天与 100 条双阈值执行 LRU 治理。

---

## 2. 背景与愿景 (Vision)

构建专属于用户的数字化身与海马体记忆中枢（One Free-Me）：
- **用户基础画像**：沉淀用户物理与生活属性、硬件配置与日常环境；
- **工程资产与路径**：记录 GitHub 仓库根目录（`$github_dir`）及关联项目拓扑；
- **别名与操作映射**：映射常用项目代号（如 `OneToDo`、`vfrp`）至实际工程路径与常用操作；
- **自驱动实操执行**：任务执行前优先在海马体中检索本机专属实操手册，实现精准闭环。

---

## 3. 记忆沉淀机制 (Memory Ingestion)

海马体文档统一保存在 `$github_dir/one-hippocampus/` 下，具体文章全部使用中文命名。

### 3.1 模式一：自动记忆（伴随增量追加）
* **触发场景**：日常编码推进中产生实质代码修改、配置变更或架构决策时，AI 主动增量记录。
* **执行流程**：
  1. 检查 `memory/` 是否已存在当天同主题文件；若无则创建 `memory/<YYYY-MM-DD_中文主题>.md`，若有则追加记录；
  2. 记录演进过程、改动要点、踩坑排障与当前状态；
  3. 执行脚本完成打卡与置顶：
     ```bash
     python3 scripts/free_me.py recent "<中文主题>" "memory/<YYYY-MM-DD_中文主题>.md"
     ```
  4. 增量同步索引：
     ```bash
     python3 scripts/free_me.py sync "memory/<YYYY-MM-DD_中文主题>.md"
     ```

### 3.2 模式二：收工记忆（会话情景复盘）
* **触发词**：用户输入“**收工**”或“**超级我**”。
* **执行流程**：
  1. **价值评估**：仅当本次会话包含实质改动、关键决策或新增事实时执行沉淀；若无新增事实或自动记忆已完整覆盖，则完成确认后退出；
  2. **情景记录**：以完整叙事方式撰写会话实操复盘至 `$github_dir/one-hippocampus/memory/<YYYY-MM-DD_中文主题>.md`，涵盖背景目标、决策过程、改动清单与避坑要点；
  3. **流水打卡与治理**：
     ```bash
     python3 scripts/free_me.py recent "<中文主题>" "memory/<YYYY-MM-DD_中文主题>.md"
     python3 scripts/free_me.py sync "memory/<YYYY-MM-DD_中文主题>.md"
     ```
  4. 极简汇报执行结果。

## 4. 辅助脚本规范 (`scripts/free_me.py`)

### 4.1 脚本定位
在 `scripts/` 目录下提供单一 Python 脚本 `scripts/free_me.py`，全局环境可通过 `free-me` 简写调用。本地数据库 `.fts.db` 存放于海马体仓库根目录，加入 `.gitignore` 仅在本地维护。

### 4.2 子命令规格

| 子命令 | 参数 | 说明 |
| :--- | :--- | :--- |
| `search` | `<关键词>` | BM25 全文检索：基于 CJK 双字与英文分词，输出相关度评分与匹配高亮片段。 |
| `recent` (别名 `touch`) | `<实体/主题> [指针/简述]` | 近期活跃流水打卡：刷新时间戳为今天并移至表格首行（置顶），自动执行 60 天 / 100 条双阈值淘汰并同步索引。 |
| `clean` | 无 | 手动治理近期记忆：根据 60 天与 100 条双阈值清理旧记录，并同步索引。 |
| `sync` | `<相对路径>` | 增量同步单篇 Markdown 文档到 `.fts.db`；文件删除时清理索引条目。 |
| `rebuild` | 无 | 全量扫描海马体目录重建 `.fts.db`。 |

### 4.3 检索优先级
AI 执行任务或查询记忆时遵循以下寻路顺序：
1. **代号解析**：查阅 `system/aliases.md` 解析特定代号对应的项目路径与常用指令；
2. **BM25 检索**：调用 `python3 scripts/free_me.py search "<关键词>"` 秒级检索文档候选；
3. **语义索引**：未精确命中时，遍历 `INDEX.md` 与 `onewiki/index.md` 结构导航；
4. **活跃记忆**：结合 `hot.md` 与 `recent.md` 获取当前高频上下文。

## 5. 存储架构：海马体数据仓 (`$github_dir/one-hippocampus/`)

```
$github_dir/one-hippocampus/
├── .gitignore               # 忽略本地 .fts.db 数据库
├── .fts.db                  # 本地 BM25 检索数据库（本地维护）
├── INDEX.md                 # 海马体总索引：全局导航与冷知识目录
├── hot.md                   # 热记忆：手工维护的高频常驻信息
├── recent.md                # 近期记忆流水：访问置顶与双阈值（60天/100条）控制
├── system/                  # 系统级基准与配置
│   ├── constitution.md      # 行为准则
│   ├── profile.md           # 基础画像、网络拓扑、常驻端口与仓库路径
│   └── aliases.md           # 项目代号与高频指令映射表
├── memory/                  # 情景记忆（按时间命名的完整叙事长文）
│   └── YYYY-MM-DD_中文主题.md # 会话实操长文（背景、决策、改动、避坑）
└── onewiki/                 # 领域实操规程库（按分类存放，中文命名）
    ├── index.md             # 实操规程总大纲与领域索引
    ├── 网络/                # 代理、穿透、DNS、路由等实操规程
    ├── 硬件/                # 显卡、电源、硬件排障等实操规程
    └── AI/                  # 模型、网关、Token 等配置实操规程
```

## 6. 近期记忆生命周期规范 (`recent.md`)

* **存储位置**：`$github_dir/one-hippocampus/recent.md`
* **条目格式**：`| 实体 / 主题 | 对应文档指针 / 内容简述 | 最近访问时间 |`（日期格式：`YYYY-MM-DD`）
* **访问置顶 (LRU Top)**：条目凡经查用、更新或新增，访问时间戳均更新为当天，并移至表格首行（表头下方）。
* **双阈值淘汰**：
  1. **时间阈值**：保留 60 天内的条目，超期记录自动淘汰；
  2. **数量阈值**：最大保留 100 条记录，超出部分按访问时间倒序截断；
  3. **自动同步**：调用 `scripts/free_me.py recent` 时自动触发双阈值清理与索引同步。
