# 查询 Markdown Wiki

从已编译的个人 Wiki 中回答问题。

1. 读取 `onewiki/index.md`，然后读取问题所需的最少链接主题和规范页面集合。
2. 当答案跨越相关主题、项目、人员、工作流、决策或证据时，跟随语义链接。
3. 仅从 `onewiki/` 中回答。不要检查 `raw/`、外部源文件或不受支持的文件。
4. 引用相关的 Wiki 路径，并在这些标签重要时区分已确认（confirmed）、源码支持（source-backed）、争议中（contested）和观察列表（watchlist）知识。
5. 如果缺乏答案，请如实说明并推荐 `ingest`；不要根据假设填补缺口。
6. 不要修改或移动文件。如果一个答案值得保存，推荐将其另存为 `raw/` 下的 Markdown 源文件并运行 `ingest`。

完成意味着答案是简洁的、可追溯到规范 Wiki 页面的，并且对缺失或冲突的知识保持诚实。
