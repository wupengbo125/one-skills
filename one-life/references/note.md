# 生活记录 (note)

向远端 `raw/` 写入或更新生活源材料。

## 远端通道写入：
调用 **one-ghfile** skill（先读其 `SKILL.md` 按其方法执行）
## 操作完成
操作完更新本地仓库（`cd ~/onespace/github/one-life && git pull`），并汇报已更新本地仓库。

## 1. 记日记 / 记录生活 / 存生活材料（唯一写入方式）
1. **命名落盘**：写入远端 raw 根目录，如：`raw/<YYYY-MM-DD>-<简短slug>.md`，保留用户原文或关键事实（长短皆可，不再区分条目/文档）。
2. **极简反馈**：反馈落盘路径。

## 2. 更新已有文档，
在本地操作
1. 先同步仓库最新状态
2. **检索定位**：调用 `python3 scripts/fts.py search "<关键词>"` 定位目标文档。
3. **确认修改**：说明拟改动内容，确认后精准更新。
