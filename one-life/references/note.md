# 生活记录 (note)

向远端 `raw/` 写入或更新生活源材料。

## 远端通道写入：
调用 **one-ghfile** skill（先读其 `SKILL.md` 按其方法执行）
## 操作完成
操作完更新本地仓库（`cd ~/onespace/github/one-life && git pull`），并汇报已更新本地仓库。

## 1. 记到生活大本子（一句话清单/条目/生活碎念）
→ **条目模式**：
1. 统一写入远端 `raw/misc/生活大本子.md`，**不新建文件、不预设分类**
2. 文件内按 `## 小节` 自然分类，判断内容属于哪个小节（如 "见闻"、"购物"、"饭局"、"电影"、"日常"、"情绪"），有则追加到该小节下一条 `-`，无则新建 `## 小节` 再追加

## 2. 记日记 / 记录生活 / 存生活材料（文档模式）
1. **命名落盘**：写入远端 raw 根目录，不准分类，如：`raw/<YYYY-MM-DD>-<简短slug>.md`，保留用户原文或关键事实。
2. **极简反馈**：反馈落盘路径。

## 3. 更新已有文档，
在本地操作
1. 先同步仓库最新状态
2. **检索定位**：调用 `python3 scripts/fts.py search "<关键词>"` 定位目标文档。
3. **确认修改**：说明拟改动内容，确认后精准更新。
