# 边界：什么该进 one-life

## 三问定仓

| 问自己 | 答案 → 去向 |
| :--- | :--- |
| 这是 AI 干的活 / 改了什么代码？ | one-hippocampus（海马体） |
| 这是可复用知识、读书笔记、方法论、攻略？ | one-llmwiki（知识库） |
| 这是我这个人的一次经历、行程、心情、人际？ | **one-life** |

## 防误触发

- 用户在写代码 / 改配置 / 提交代码的语境里说过的话 → **不**进 one-life
- 用户说"记笔记""记到大本子""存一下这个知识" → one-wiki
- 用户说"记住以后都…""不要再…"（稳定行为规则）→ 海马体 personal/preferences.md，不是日记
- 一次性的、不重复的琐事也属于 one-life（今天的午饭吃了啥也值得记——那是生活痕迹，不是知识）

## 反向约束

- one-life 仓**不装 pre-commit 记忆门禁**：随手记一条不该被拦
- 日记不做知识化改造：不要为了整齐去改用户原文
