# 生活知识查询 (query)

从已编译的 `onelife/` 中回答生活经历、回忆并追溯出处。

仓库在 `~/onespace/github/one-life/`，两棵树：

```
raw/       原始日记（原料）    <YYYY-MM-DD>-<slug>.md，ingest 后归档进 raw/<YYYY>-<season>/
onelife/   编译后的生活知识（查这里）  index.md 总索引
```

## 意图分流：先选手段

「最近」「有哪些」这类问句里没有可搜的内容词，索引里搜不到；先按下表挑手段。

| 问法 | 手段 |
| :--- | :--- |
| 某段经历、某个词是怎么说的（人物、地点、物品、原话） | `python3 scripts/fts.py search "<关键词>"` |
| 某个方面、某一类里都有什么（"有没有…相关的"） | 从索引进：总索引 `onelife/index.md`，顺双链下钻 |
| 最近、最新、时间 | 列目录按时间倒序：`ls -t raw/ raw/*/`（新日记在 `raw/` 根下，ingest 归档进 `raw/<YYYY>-<season>/`，文件名带 `YYYY-MM-DD`） |

**完成标准**：一条路走空就换下一条，三条都走完才算查完；回答里说清走了哪几条。

## 执行步骤

1. **定位**：按意图分流选出的手段定位相关生活概念、实体（人物、地点、物品）与生活摘要。
2. **查阅双链上下文**：直接阅读命中页面，沿 Obsidian 双链追溯人物关系、事件脉络与经历。
3. **精准回答与引用**：基于 `onelife/` 内容合成回答，并标明引用的生活 Wiki 页面与时间节点。
4. **优质结论沉淀**：若解答或互动中产生高价值生活感悟或细节梳理，建议用户通过 `note` 存入 `raw/` 待后续编译。
