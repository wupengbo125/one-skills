# 待办插件 Local/主干 徽标支持

## 背景诉求
待办插件中，任务若运行在 Local 模式（主干），在右上角徽标区（置顶、待办/ISSUE等）左侧显示松树 `🌲` 徽标以节省空间；如果是 Worktree 独立分支则不显示。

## 关键改动
1. `paseo-plugins/one-todo/server/executor.ts`：
   - 移除脆弱的外部 git 子进程探测；
   - 开跑事件中，只要是 Local 模式（非 worktree 独立分支），直接写入 `branchTag: "local"` 存入待办 JSON。
2. `paseo-plugins/one-todo/client/todo.tsx`：
   - 待办卡片非 pending 且为 Local 模式时，在置顶与待办/ISSUE 徽标左侧渲染单字符松树 `🌲` 徽标。
