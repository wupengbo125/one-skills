# 待办插件 main 分支标签支持

## 背景诉求
待办插件中，任务开跑后如果运行在 main 分支，在右上角徽标区（置顶、待办/ISSUE等）左侧显示 main 标签；如果是其他分支则不显示。要求开跑事件中写入待办 JSON，下次加载待办直接展示。

## 关键改动
1. `paseo-plugins/one-todo/shared/todo.ts`：
   - `todoSchema` 与 `updateTodoRpc` 增加可选字段 `branchTag?: string`。
2. `paseo-plugins/one-todo/server/executor.ts`：
   - 任务开跑事件（`handleStartTodo` -> `launchAndSaveTodo`）检查当前运行分支（显式 worktree 分支或 git 探测），若是 main 分支则写入 `branchTag: "main"`，持久化至 `todos.json`。
   - `handleResetTodo` 重置待办时清空 `branchTag`。
3. `paseo-plugins/one-todo/server/todo.ts`：
   - `handleUpdateTodo` 支持更新 `branchTag`，且重置为 pending 状态时自动清空。
4. `paseo-plugins/one-todo/client/todo.tsx`：
   - 待办卡片右上角徽标区，在任务非 pending 且 `t.branchTag === "main"` 时，于置顶及类型徽标左侧渲染 `main` 徽标。
