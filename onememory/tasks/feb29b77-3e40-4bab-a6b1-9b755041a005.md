# 任务案卷：待办插件普通模式前导词多份增删改选与折叠栏优化

- 会话ID: feb29b77-3e40-4bab-a6b1-9b755041a005
- 日期: 2026-10-01
- 项目: one-skills (paseo-plugins/one-todo)

## 需求背景
待办插件普通模式开场向导词支持自由增加、删除、编辑与选择使用哪一份（存放在 `prompts/initial/<名>.md`）。同时优化折叠栏交互，避免伪输入框嵌套。

## 核心改动
1. **文件与存储**：
   - 普通前导词统一存放在 `prompts/initial/` 目录，每个 `.md` 文件对应一份前导词。
   - 文件名即选项名，初始以 `开场向导词.md` 为初始文件，无任何硬编码特殊名称。
2. **服务端与 RPC**：
   - `listInitialPromptsRpc`：扫描目录返回列表与选中项。
   - `reviewTemplateRpc`：支持 `newName` 参数实现保存时文件重命名。
   - `deleteInitialPromptRpc`：支持安全删除指定前导词并回退选中项。
3. **前端交互与样式**：
   - 将外层折叠头（`collapseRow`）从原有的带边框输入框样式（`s.chip`）重构为纯文本标题折叠样式（带 `▶ / ▼` 图标），默认收起保持表单紧凑。
   - 展开后展示内层前导词选择下拉框（`[ 前导词: xxx ▼ ]`）与【+ 新增前导词】。
   - 支持前导词标题直接修改（保存时重命名对应文件）与【删除】操作。

## 验证结论
- `npm run typecheck` 0 报错。
