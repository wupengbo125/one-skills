# 任务案卷：待办评审界面优化与评审链路闭环

- 会话ID：`8250c6d6-e3a7-45c9-b5a7-44b068c0358e`
- 日期：2026-09-26
- 项目：`~/onespace/github/one-skills`

## 背景诉求
1. 用户反馈待办插件（one-todo）评审界面文案生硬口语化（如「发给它」、「发送提示词」等），排版杂乱，要求进行高雅化与整齐化方案设计。
2. 落地改造后，解决电脑端 Tab 竖向排版、轮数选择「不限」字折叠、复制提示常驻不散、按钮尺寸风格割裂等一系列交互硬伤。
3. 按用户需求精简评审入口为单一动作「评审」，支持自动检测评审会话生命周期（未归档则继续、已归档则开新）。
4. 修复自动评审下发会话 ID 丢失问题，以及规范 `one-audit-list` 技能需求来源于用户确认的平铺 Plan。

## 排查与决策
1. **排版坍塌根因**：React Native for Web 环境下，内联样式 `{ flex: 0 }` 会被解析为 `flex-basis: 0`，导致文字被压成单字竖向折行。将 Tab 和轮数按钮替换为 `flexShrink: 0, minWidth: ...` 彻底解决。
2. **Tab滑动联动**：横向 ScrollView 增加 `onScroll` 与 `scrollEventThrottle={16}`，解决桌面浏览器不触发 `onMomentumScrollEnd` 导致滑屏不切 Tab 的问题。
3. **按钮语义统一**：去除 15px 巨型内边距，统一为 40px 高度；主操作统一使用高亮绿，辅助操作采用透明底线框（`outlineBtn`），废除容易混淆为禁用态的死灰色（`surface2`）。
4. **单按钮评审闭环**：删除开新/接着聊分裂按钮，只留「评审」；底层通过 `isReviewSessionAlive` 探测，会话存活直接注入，会话归档/删除则自动起新工作区。
5. **复制气泡就地自毁**：点击「复制意见」在按钮上方弹 1.5 秒微型气泡 `已复制` 自动淡出，顶部通知加 2.5 秒自清除定时器。
6. **下发目标丢失修复**：待办切换 pending 时不再粗暴清空 `agentIds`；下发流转时自动寻址当前工作区活跃 Agent 并回写固化到待办数据，杜绝假空数组。
7. **技能铁律修改**：`one-audit-list` 明确规定清单内容必须且只能来源于用户确认过的平铺 Plan 原话，多轮融合覆盖，严禁脑补。
