# one-orca-race 分支名生成：一路改错到定稿

- 会话: 01a0ba83-ad85-7e10-ae3a-c71cec63072f
- 日期: 2026-09-20
- 主题: race 脚本自动生成的分支名

## 背景诉求
赛马时多个 Agent 并发跑同一个 Issue，分支名会撞。用户要求：分支名加随机三位数字（放在马后面），agent 后面带上模型（如果指定了模型）。

## 迭代与错误方向（一路被用户怼回来）

| 轮次 | 我做的 | 用户反馈 | 教训 |
| :--- | :--- | :--- | :--- |
| 1 | 随机 3 位**整轮只生成一次** | 「两个都指定了 OMP，给我直接生了两个 154」 | 作用是防撞时，随机量要按**并发实体**（每匹马）生成，不是按批次 |
| 2 | 截断：前 6 个词 + 限长 40 字符 | 「40 个字符相当于没有砍」 | 自造双阈值没人能预期 |
| 3 | 改成含汉字取前 6 个字符 | 「`[Refactor]` 也被算进去了，标题根本没截断」 | 标题开头的 `[xxx]` 是元信息，截断前得先剥 |
| 4 | 剥标记 + 每位马独立随机 | 「分支变成 `🐎-013-omp-`，尾巴空的」 | 见「真机 bug 根因」 |
| 5 | 修 locale + 兜底 + 重测 | **「干脆别做截断了，我以后注意把标题写短」** | 需求本身是伪需求时，最省事的方案是删掉它而不是修好它 |

## 真机 bug 根因（都由用户实测发现）

1. **locale 导致按字节截断**
   - `LANG=C` 时 bash `${var:0:6}` 按**字节**切，中文 1 字 3 字节 → 切出半个汉字（非法 UTF-8），终端渲染成空白，看起来就是「尾巴没了」
   - 早期 `sanitize_ref` 用 `[^A-Za-z0-9一-龥._-]` 这种带多字节区的字符类做替换，C locale 下按字节匹配，中文会被替换成一堆 `-`，折叠去首尾后直接变空串
   - **结论**：bash 里对多字节做 `${var:0:N}` 前必须先锁 UTF-8 locale；能不做就不做

2. **剥标记把标题剥空**
   - 标题本身就是 `[赛马测试]` 这类纯标记时，剥完成空，分支尾剩 `🐎-xxx-omp-`

3. **sed 字符类不可靠**
   - `sed 's/[ ~^:?*[\]\\]/-/g'` 里的 `[` `:` 实际没被替换，分支名仍含非法字符

## 最终方案（第 5 轮定稿）
- 分支名：`<🐎-><随机3位>-<agent>[-<model>]-<Issue标题>`
- 随机 3 位：每位参赛马各一个，同轮内去重
- **标题不截断**，原样进来，只做两件事：
  - `sanitize_ref`：逐字符参数展开，把 git ref 非法字符（空格 `~ ^ : ? * [ ] \ /`）换成 `-`，只动 ASCII 字节（UTF-8 多字节 ≥0x80，天然不受影响），不依赖 locale
  - 标题为空时用 `issue-<编号>` 兜底
- 为此，之前加的**强制 UTF-8 locale 块**和 **`strip_title_tag`** 一并删除（截断没了，这两样就成了死代码）

## 验证
- 真实脚本 `--dry-run` 在默认 env 与 `LC_ALL=C LANG=C` 下输出一致
- 用例（`[Refactor] 整体结构治理…`、`[P1] 支持 a:b 与 [tag] 混排 ~ 路径 ^ 符号 * 通配`、`修复 bug：登录失败 / 会话过期`、空标题、长英文标题）全部通过 `git check-ref-format --branch`

- `one-orca-race/SKILL.md`：核心能力第 4 条
