会话：01a0cc42-9a9b-795b-8a53-b15b0c569701

## 背景诉求
Issue #5：现名 `one-write-skill` 用语音输入法念出来时，`write` 与 `right` 同音，ASR 无法稳定区分，名字既别扭又不像一个身份。用户要改名，且新名必须"hold 住"这个技能（写/改 Agent 文档的规矩）。

## 决策过程
1. 我先提了隐喻名（forge/scribe/loom 等），被用户否掉："和创造技能、修改技能没有任何关系"。
2. 改提字面名（one-skill-author / -writer / -builder / -editor）。
3. 用户最终拍板：**`one-writing-skill`**（对应 "One Writing Skill"）。

## 代码结论
纯改名，两处：
- `git mv one-write-skill one-writing-skill`（含 `references/authoring.md`、`references/mechanics.md`）
- `one-writing-skill/SKILL.md` 的 `name:` 字段 → `one-writing-skill`

## 涉及产物 / 影响面
- `install.sh` 自动扫描目录、`BLUEPRINT.md`/`CODE_WIKI.md`/`skills-lock.json`/`one-agents.md` 均无该名引用，无需改。
- 本机 `~/.codebuddy/skills/`、`~/.agents/skills/` 两处软链指向主仓，改名合并进 main 后重跑 `install.sh` 即可换成新名并清旧链（用户选择"合并后再装"）。
