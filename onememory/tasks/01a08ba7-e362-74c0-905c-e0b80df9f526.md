# [01a08ba7] 重构双轨记忆系统规范与本地 pre-commit 门禁

会话 ID：01a08ba7-e362-74c0-905c-e0b80df9f526
记录时间：2026-09-10 23:28

## 背景与痛点
- 此前记忆全部堆在全局海马体按日切分的文件中，跨项目混杂，无法快速召回“本项目最近改了啥”。
- 原有 commit-msg 跨仓校验 hash 机制导致频繁需要双重提交与 rebase 冲突。
- 本地环境缺乏会话 ID 注入与任务详情沉淀。

## 核心设计与方案
- **项目随身记忆 (onememory)**：
  - 目录命名为 `onememory/`（小写无点，对齐 `onewiki/`，天然规避 `.*` gitignore 规则）。
  - `onememory/timeline.md`：全项目单一时间线总流水，按时间顺序列出每次修改。
  - `onememory/tasks/<会话ID>.md`：详细案卷，记录背景、过程、结论与产物。
  - 与代码同批原子提交，由本地 `pre-commit` hook 强阻断未记记忆的提交。
- **全局海马体 (one-hippocampus)**：
  - 解除跨仓 hash 强绑定，单向追加宏观日程大盘：`- HH:mm [项目名] [会话ID] 摘要`。
  - 专职作为跨项目全景拼图与人格偏好中心。
