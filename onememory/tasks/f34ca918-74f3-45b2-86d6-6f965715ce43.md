# one-todo 插件体验优化与 Issue 联动修复

- 会话 ID: f34ca918-74f3-45b2-86d6-6f965715ce43
- 日期: 2026-09-24

## 背景与诉求
用户要求对 `paseo-plugins/one-todo` 插件进行 7 项 UX 与功能增强，并在实际调试中修复 GitHub Issue 联动、项目关联、草稿保存和弹窗交互一致性。

## 主要改动
1. **多选技能联动** (`shared/todo.ts`, `server/todo.ts`, `client/todo.tsx`):
   - 服务端直接遍历 `~/.agents/skills/` 与 `~/.claude/skills/` 目录名返回技能列表。
   - 待办支持绑定多个技能，开跑时自动在 prompt 前注入 `[使用技能: ...]`。
2. **偏好记忆与配置回填** (`server/store.ts`, `server/todo.ts`, `client/todo.tsx`):
   - 新增偏好文件 `~/.paseo/plugin-data/one-todo/preferences.json`，记住最后选用的 Provider、Model、项目与技能。
   - 开跑/创建时自动回填上次配置；创建分支时根据标题前 20 字符自动生成合法分支名。
3. **完成任务当天过滤** (`client/todo.tsx`):
   - 已完成任务列表仅展示当天完成项。
4. **Issue 联动与弹窗体验** (`client/todo.tsx`):
5. **one-memory 探针增强** (`one-memory/references/write-memory.md`):
   - 第二优先级探针列表补充 `$PASEO_AGENT_ID`，确保在 Paseo 运行环境下自动获取会话 ID。
   - 点击 Issue 卡片先拉取完整正文并直接打开编辑/运行弹窗，不触发未确认的偷存。
   - 修复 Issue 关联项目被默认目录强行覆盖的优先级问题，优先绑定 Issue 自身仓库。
   - 保存草稿时过滤无效空 Agent，且保存成功后保持弹窗不强制关闭。
   - 统一 Issue 直接打开与存入待办后的 isolation 默认行为为 local。
