## 排查得到的事实（动手前已查完）

- install.sh 的 TARGETS 表里 **本来就有** `"codebuddy|skills-dir|$HOME/.codebuddy/skills"`（2026-09-15 补的技能位），给 codebuddy 的规则位也在。
- codebuddy 侧技能位 `~/.codebuddy/skills` 里 20 个 one-* 技能都在（2026-09-27 21:28 装的软链），**只缺 `one-plan`** —— 它是 9/28 01:04 才进仓库，晚于上次安装。
- 同一技能在 `~/.agents/skills`、`~/.trae-cn/skills` 也缺，属同一原因。
- 交互菜单实测能列出 one-plan（能装，只是要手点）。
- 真缺口不是"位置的配置错了"，而是**脚本只能进菜单手点**，命令行/Agent 没法直接装，新技能就一直漏。

## 结论与决策

在 install.sh 加**直装入口**，绕过菜单：

```
bash install.sh --to <agent> [技能名...]     # 不点名技能 = 仓库里全部技能
bash install.sh --to codebuddy
bash install.sh --to codebuddy one-plan
```

实现：顶部解析 `--to`（普通用法 `install.sh [源目录]` 保持不变）→ 菜单那两步用 `if [ -z "$DIRECT_AGENT" ]` 包住 → TARGETS 派生后加直装分支（只动技能位，不碰钩子/.gitignore/规则位），装完 exit 0。

已跑 `bash install.sh --to codebuddy`：20 个技能全部链到 `~/.codebuddy/skills`，`one-plan` 补上；逐个核对无缺。菜单老路复测可用，坏 agent 名会报「没有这个 agent 的技能位」。
