# one-todo 待办配置可保存：技能/马回填 + 默认一匹马

- 会话 ID: 01a0d2fc-d523-75e2-8e28-54595488dd73
- 日期: 2026-09-24

## 背景与诉求
用户要求待办里的技能、模型（马）能真的存住，提前写好下次直接点开跑，不用开跑时临时选；并且「放马」区默认就该有一匹马，不用点「+ 加一个」，这匹默认马 = 上次选的那匹。

## 主要改动
1. **打开待办回填已存配置** (`client/todo.tsx`):
   - `openDetail` 里算了 `agents` 却没赋值，导致打开永远是 0 匹马；`skills` 也没回填。
   - 补 `d.agents = agents`、`d.skills = t?.skills ?? []`，无马时给 `[defaultAgent]`（= 偏好里上次的 provider/model）。
2. **技能独立存盘** (`server/todo.ts`):
   - `handleUpdateTodo` 中 `skills` 赋值嵌在 `if (p.agents !== undefined)` 内，只改技能存不住；挪到分支外独立生效。

## 追加：重连按钮
用户场景：会话中断几次，agent 挂掉后待办被打回 failed（显示「重置」），但会话后来被救活，希望能「重连」接回去，等 worktree 关闭时待办才算完成。

1. **完成判定机制**（既有）：`workspace.archived` 只处理 status=running 且 workspaceId 匹配的待办；`agent.turn_ended` 非 completed 即将待办打回 failed。
2. **重连** (`client/todo.tsx`, `server/todo.ts`):
   - failed 卡片在「重置」旁新增「重连」按钮，仅当待办有 workspaceId 或 agentIds 时显示，点击置回 running。
   - `handleUpdateTodo` 在 status 改为 running 时清掉 error/finishedAt，不留失败痕迹。
   - 重连后靠 workspace.archived 正常收尾，无需重新绑定 agent。

## 约定
- paseo 插件改动直接改主仓工作区（`~/.paseo/config.json` 插件 path 指向主仓），这类要立刻看效果的需求不开 worktree 分支；worktree 仍用于 agent 干活的隔离。
