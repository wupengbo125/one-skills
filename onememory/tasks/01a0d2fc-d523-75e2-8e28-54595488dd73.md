## 背景与诉求
用户要求待办里的技能、模型（马）能真的存住，提前写好下次直接点开跑，不用开跑时临时选；并且「放马」区默认就该有一匹马，不用点「+ 加一个」，这匹默认马 = 上次选的那匹。

## 主要改动
1. **打开待办回填已存配置** (`client/todo.tsx`):
   - `openDetail` 里算了 `agents` 却没赋值，导致打开永远是 0 匹马；`skills` 也没回填。
   - 补 `d.agents = agents`、`d.skills = t?.skills ?? []`，无马时给 `[defaultAgent]`（= 偏好里上次的 provider/model）。
2. **技能独立存盘** (`server/todo.ts`):
   - `handleUpdateTodo` 中 `skills` 赋值嵌在 `if (p.agents !== undefined)` 内，只改技能存不住；挪到分支外独立生效。

## 约定
- paseo 插件改动直接改主仓工作区（`~/.paseo/config.json` 插件 path 指向主仓），这类要立刻看效果的需求不开 worktree 分支；worktree 仍用于 agent 干活的隔离。
