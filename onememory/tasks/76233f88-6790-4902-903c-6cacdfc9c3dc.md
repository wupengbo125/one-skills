# Task: one-todo 支持 agy Terminal 模式开跑与跳转

- 会话 ID: `76233f88-6790-4902-903c-6cacdfc9c3dc`
- 日期: 2026-09-25

## 背景与诉求
用户希望 Paseo 插件 `one-todo` 能对接 agy CLI，通过 Paseo 终端（Terminal）模式而非 ACP 模式运行。Paseo 可以启动终端，开始命令可以设定为 `agy`，向终端传入提示词即可完成任务交互。

## 关键改动
1. `paseo-plugins/one-todo/shared/todo.ts`:
   - `todoSchema` 增加 `terminalIds?: string[]` 字段，用于记录终端 ID。
2. `paseo-plugins/one-todo/server/todo.ts`:
   - `handleListProviders` 注入 `agy` Provider。
   - `handleListModels` 为 `agy` 提供常用模型列表（以 `gemini-3.8-flash-medium` 为默认）。
3. `paseo-plugins/one-todo/server/executor.ts`:
   - 提取 `launchAgentOrTerminal`，当 `provider === "agy"` 时，调用 `ws.terminals.create` 启动终端执行 `agy --dangerously-skip-permissions [-m model] -i <prompt>`。
   - 收集 `terminalIds` 并存入 Todo。
4. `paseo-plugins/one-todo/client/todo.tsx`:
   - 针对 Terminal 类型任务，跳转 `↗` 按钮直接调用 `navigation.openWorkspace({ workspaceId: t.workspaceId })` 定位至对应 Workspace 终端面板。
