# Task: one-todo 对接 antigravity acp 与 cli 并支持开跑与跳转

- 会话 ID: `76233f88-6790-4902-903c-6cacdfc9c3dc`
- 日期: 2026-09-25

## 背景与诉求
用户希望 Paseo 插件 `one-todo` 能对接 agy CLI，通过 Paseo 终端（Terminal）模式而非 ACP 模式运行。Paseo 可以启动终端，开始命令可以设定为 `agy`，向终端传入提示词即可完成任务交互。同时将两个 Provider 命名为 `antigravity acp` 和 `antigravity cli`。

## 关键改动
1. `paseo-plugins/one-todo/shared/todo.ts`:
   - `todoSchema` 增加 `terminalIds?: string[]` 字段，用于记录终端 ID。
2. `paseo-plugins/one-todo/server/todo.ts`:
   - `handleListProviders` 将 ACP 提供商重命名为 `antigravity acp`，将 Terminal 模式重命名为 `antigravity cli`。
   - `handleListModels` 映射两者并为 `antigravity cli` 提供常用模型列表。
3. `paseo-plugins/one-todo/server/executor.ts`:
   - `resolveProviderField` 支持 `antigravity acp`。
   - `launchAgentOrTerminal` 识别 `antigravity cli`，启动终端执行 `agy --dangerously-skip-permissions [-m model] -i <prompt>` 并记录 `terminalIds`。
4. `paseo-plugins/one-todo/client/todo.tsx`:
   - 针对 Terminal 类型任务，跳转 `↗` 按钮直接调用 `navigation.openWorkspace({ workspaceId: t.workspaceId })` 定位至对应 Workspace 终端面板。
