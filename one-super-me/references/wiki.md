# Wiki 记录指南

当记忆内容涉及**本机操作、配置、规程、排障方案**时，除了存入 `memory/` 外，**同步记录到 `onewiki/`**。

## 记录位置

- **海马体**：`memory/<YYYY-MM-DD_主题>.md`
- **Wiki 手册**：`onewiki/<领域>/<主题>.md`

## 何时同步记录到 Wiki

记忆中包含以下内容时，直接存进 `onewiki/`：

- 本机操作步骤、配置方法
- 环境管理、网络代理、硬件控制等规程
- 故障排查与解决方案
- 可复用的操作清单

## 文件组织

根据内容领域存放：

| 领域 | 路径 |
| :--- | :--- |
| 技术操作 | `onewiki/技术/` |
| 其他领域 | `onewiki/<自定义领域>/` |

## 同步到 Wiki 后

1. 更新 `onewiki/index.md` 添加链接
2. 执行 `git add onewiki/ && git commit -m "..." && git push`

完成。
