# 避坑手册沉淀指南 (Wiki Reference)

> 当用户发出明确指令“**记一下**”、“**记到文档**”、“**沉淀避坑手册**”时，按本指南执行。
> **核心原则**：`onewiki/` 是用户的私有 Skill 避坑手册库。按领域分类存放（如网络、硬件、AI等），并同步更新大纲索引。

---

## 执行步骤

### 1. 确定领域分类与文件路径
* **分类规则**：根据手册涉及的领域选择或创建对应目录，如：
  - `onewiki/网络/`：代理、穿透、DNS、路由、VPN 等
  - `onewiki/硬件/`：显卡、电源、驱动、外设、散热等
  - `onewiki/AI/`：模型、网关、Token、微调、推理等
  - 如属全新领域，可新建简洁中文领域分类目录（如 `onewiki/开发/`）。
* **文件路径**：`$github_dir/one-hippocampus/onewiki/<领域分类>/<全中文实操手册名称>.md`
* **命名要求**：100% 全中文命名（如《代理服务节点切换与运维.md》）。
* **内容结构**：
  ```markdown
  # <全中文实操手册名称>

  ## 1. 适用场景与前置环境
  - 适用机器/环境、前置依赖与配置文件位置。

  ## 2. 核心操作步骤与验证命令
  - 具体执行命令（真实可跑通，参数明确）。
  - 核心配置要点与示例。

  ## 3. 关键踩坑点与排障经验
  - 遇到过的报错、冲突与排查手段。
  - 避坑关键防护与恢复建议。
  ```

---

### 2. 技能总大纲登记
打开 `$github_dir/one-hippocampus/onewiki/index.md`，在对应领域小节下登记链接与解决要点：
```markdown
- [<全中文实操手册名称>](./<领域分类>/<全中文实操手册名称>.md)
  - **核心解决**：一句话说明解决什么问题、避开什么坑。
```

---

### 3. 即时写库与极简汇报
1. **BM25 索引同步**：
   ```bash
   super-me sync "onewiki/<领域分类>/<全中文实操手册名称>.md"
   ```
2. **终端极简汇报**：
   只答一句话结果，例如：“已完成《onewiki/<领域分类>/<全中文实操手册名称>.md》沉淀并同步索引。”
