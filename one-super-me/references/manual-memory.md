# 手工记忆操作指南 (Manual Memory Reference)

> 当用户在会话中主动输入“**收工**”或“**超级我**”时，按本指南执行。
> **核心原则**：用户零心智负担，AI 自行甄别；宁缺毋滥，严防垃圾；像人类写总结一样连贯记录做过的事，严禁切碎抽取零散实体。

---

## 执行步骤

### 1. 防垃圾严苛门禁（宁缺毋滥）
- 审视本次会话全过程（工具调用、修改的文件、排查的问题、交流的共识）。
- **如果本轮仅为简单问答、日常闲聊、无新工程事实、无重大决策与改动**：
  - **绝不落盘任何文件**；
  - 仅极简回复一句话：“本次会话无新增硬核认知，已完成。”并结束流程。

---

### 2. 情景记忆完整沉淀（像人类一样记事）
若存在实质性工作成果：
- **若自动记忆已在会话中完整记录**：无需重复重写，仅核对是否有收尾事实遗漏，有则补齐末尾；
- **若会话中未触发自动记忆**：直接撰写一篇连贯的会话实操复盘长文：

* **文件路径**：`$github_dir/one-hippocampus/memory/<YYYY-MM-DD_中文主题>.md`（单层平铺于 `memory/` 根目录下，文件名 100% 中文）
* **内容结构**：
  ```markdown
  # <中文主题> (YYYY-MM-DD)

  ## 1. 背景与目标
  - 本次会话遇到了什么核心痛点、任务目标或需求背景。

  ## 2. 过程决策与踩坑复盘
  - 排除了哪些不可行方案，为什么放弃。
  - 达成了哪些关键共识，核心转折点是什么。
  - 解决了哪些难缠的 Bug 或逻辑死锁。

  ## 3. 最终落地与当前状态
  - 最终修改/新建了哪些文件。
  - 当前系统、工程或环境处于什么可用状态。
  ```

---

### 3. 近期流水打卡与自清洁
1. **流水打卡**：
   在 `$github_dir/one-hippocampus/recent.md` 表格末尾追加或更新一行：
   ```markdown
   | <中文主题> | memory/<YYYY-MM-DD_中文主题>.md | <YYYY-MM-DD> |
   ```
2. **执行 LRU 治理**：
   执行客户端清洁命令，自动淘汰超 60 天或超 100 条的旧条目：
   ```bash
   super-me clean
   ```

---

### 4. 即时同步与极简汇报
1. **BM25 索引同步**：
   ```bash
   super-me sync "memory/<YYYY-MM-DD_中文主题>.md"
   super-me sync "recent.md"
   ```
2. **终端极简汇报**：
   只答一句话结果，例如：“已完成今日手工记忆沉淀至 memory/<YYYY-MM-DD_中文主题>.md 并同步索引。”
