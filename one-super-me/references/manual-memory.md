# 手工记忆操作指南 (Manual Memory Reference)

> 用户显式说“**收工**”、“**超级我**”时触发。
> **核心原则**：防垃圾严苛过滤；若需记录，像人类写日记一样完整叙事；通过 `super-me recent` 自动打卡、置顶并治理近期记忆。

---

## 执行步骤

### 1. 防垃圾严苛过滤（门禁）
* **审视本次会话全过程**：
  * 是否只是日常问答、简单代码解释、已解决的常规咨询？
  * 是否有真正的配置落地、踩坑排障结论、环境变动或架构决策？
* **判定结果**：
  * **无实质增量**：不写任何文件，直接极简回复：“本次会话无新增硬核认知，已完成。”并结束。
  * **已通过自动记忆完整覆盖**：不重复写入，直接极简回复：“今日进展已在自动伴随记忆中完整沉淀，已完成。”并结束。
  * **有实质增量但未记录**：进入下一步执行沉淀。

---

### 2. 情景记忆完整沉淀（像人类一样记事）
* **文件路径**：`$github_dir/one-hippocampus/memory/<YYYY-MM-DD_中文主题>.md`（单层平铺于 `memory/` 根目录下，文件名 100% 中文）
* **内容结构**：
  ```markdown
  # <中文主题> (YYYY-MM-DD)

  ## 1. 背景与目标
  - 简述今天为什么做这件事、起因是什么。

  ## 2. 核心推进脉络与关键决策
  - 像人类日记一样按时间或逻辑叙述探索与修改过程。
  - 为什么这么改、放弃了哪些方案、关键认知是什么。

  ## 3. 落地改动与资产清单
  - 涉及的具体文件、模块或配置变动。

  ## 4. 踩坑记录与避坑要点
  - 遇到的错误现象、排障过程及最终解决方案。
  ```

---

### 3. 近期流水打卡、置顶与自清洁
执行 `python3 scripts/super_me.py recent` 命令（或简写 `super-me recent`），自动完成**流水记录、时间戳刷新、首行置顶、双阈值淘汰与索引同步**：
```bash
python3 scripts/super_me.py recent "<中文主题>" "memory/<YYYY-MM-DD_中文主题>.md"
```

> **系统底层逻辑**：
> 1. 条目格式：`| <中文主题> | memory/<YYYY-MM-DD_中文主题>.md | <YYYY-MM-DD> |`；
> 2. 访问刷新与置顶：更新时间戳为当天，并将该条目移动到表格第一行；
> 3. 双阈值淘汰：超 60 天自动淘汰，超 100 条 LRU 截断；
> 4. 自动同步索引：自动调用 `super-me sync "recent.md"`。

---

### 4. 即时同步与极简汇报
1. **BM25 索引同步**：
   ```bash
   super-me sync "memory/<YYYY-MM-DD_中文主题>.md"
   ```
2. **终端极简汇报**：
   只答一句话结果，例如：“已完成今日记忆沉淀至 memory/<YYYY-MM-DD_中文主题>.md 并同步索引。”

---

## 避坑与约束

* **禁止写规则到 memory/**：规则、权限、暗号归属于 `system/constitution.md`，`memory/` 纯粹是情景式故事日志。
* **100% 中文命名**：文档名称严禁出现英文驼峰或英文句式。
