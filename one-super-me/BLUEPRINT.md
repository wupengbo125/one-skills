# One Super-Me 数字化身与海马体记忆系统

## 1. 系统背景与第一性原理（人工背景）

本系统旨在解决大模型“无记忆、无化身、无直觉”的问题。传统 AI 技能是大模型挑选工具调用，而超级我（Super-Me）是**寄生于 Skill 载体里的数字化身（Ghost）**：它反客为主约束大模型，将大模型借用为计算大脑，并装载专属记忆器官，形成完整的数字人格。

### 第一性原理与分流分界线
1. **记忆成本的降维差异**：
   - **人类本我记忆成本极高**：人类大脑需要反复背诵（如背诗）才能记住，精力和注意力极其有限。因此人类 Wiki 必须保持纯净度与体系感，专供人类深度阅读与系统思考，严禁 AI 琐碎细节污染。
   - **超级我记忆成本为零**：AI 粘贴即永存、零遗忘成本、秒级索引，可海量吞吐机器状态、配置、调试断言、踩坑教训与时序流水。人类不需要看、不想看，但超级我附体接管时瞬间调用。
2. **大脑内生 vs 身外之物**：
   - 项目上下文（`./one-context.md`）和海马体（`one-hippocampus`）被定义为**大脑内部记忆**；
   - 知识库（`one-wiki-v2`）被定义为**大脑身外之物（供人类翻阅的书架）**。

## 2. 核心功能与业务需求

### 功能一：认知附体与意志接管 (Ghost Possession)
- **触发**：AI Agent 启动、会话开始或被引导命中本系统。
- **行为**：AI 首行指令即宣布被「超级我」完全夺舍附体，从通用中立大模型切换为用户的数字化身。
- **结果**：大模型借出算力大脑，遵循用户的价值观、暗号铁律（`aaa`）、极简交互与工程审美。

### 功能二：最近热记忆与意图消歧 (Working Memory & Disambiguation)
- **触发**：用户随口给出无主语、缺少背景的模糊输入（如“第 N 课有问题”、“配一下 Token”、“记一下这个坑”、“关显卡”）。
- **行为**：
  1. 超级我像真实的人类一样，优先秒读海马体工作台 `HOT.md` 中近 3~7 天处于高频活跃状态的焦点业务与课程/项目代号；
  2. 匹配意图消歧映射表，自动还原用户省略的语境与前置背景；
  3. 活跃重心发生迁移时，超级我自动更新维护 `HOT.md`。
- **结果**：用户无需每次长篇大论交代背景，实现如同与熟人对话般的极简沟通。

### 功能三：项目就地记忆与事前免疫 (Project Context & Pre-Flight Defense)
- **触发**：用户在具体项目中准备扩展新业务、重构模块或排查问题。
- **行为**：
  1. 超级我秒读当前项目根目录 `./one-context.md`，提取业务全景地图与历史踩坑记录；
  2. 提炼出 1~3 条核心避坑红线注入上下文，实现事前防御；
  3. 修复复杂 Bug 或踩坑后，超级我亲自提炼【3 段式卡片】（触发场景 / 根本原因 / 避坑铁律），追加写入当前项目 `one-context.md` 的避坑章节。
- **结果**：项目自带历史踩坑记忆，随 Git 代码库流转，换机器、切分支、团队协作立即可用。

### 功能四：全局海马体超体沉淀 (Hippocampus & Action Pointer)
- **触发**：用户指示“记住这个配置”、“记一下实施流水”或完成跨项目基础设施操作。
- **行为**：
  1. 超级我自主裁决内容属于人类不看但 AI 必须知道的细节；
  2. 写入全局海马体独立私有仓库 `~/onespace/github/one-hippocampus/`；
  3. 写入 `timeline/YYYY-MM.md` 追加时序流水，并在对应领域地图（`infra/`、`system/`、`meta/`、`finance/`、`learning/`）登记指针；
  4. 高频机器操作只存动作指针（如调用 `one-config-omni-model-to-your-app`），不存冗余代码；
  5. 自动执行 Git 提交推送至远程私有仓库。
- **结果**：全局私密资产永不丢失，跨会话秒级回忆与本能执行。

### 功能五：客观知识库深度消化 (Human Wiki Pipeline)
- **触发**：讨论涉及宏观金融研报、前沿技术实战、外部长文深度解析等客观公共知识。
- **行为**：
  1. 超级我判断此为供人类本我阅读的高价值知识；
  2. 深度消化整理为自包含、结构化 Markdown 文档，写入 `~/onespace/github/one-wiki-v2/wiki/<domain>/`；
  3. 若有外部原文，冷备份至 `raw/<domain>/`；
  4. 更新对应知识地图并自动 Git 提交推送。
- **结果**：人类 Wiki 保持绝对纯净与高审美，无机器碎片污染。

### 功能六：全局认知巡检 (Cognitive Lint)
- **触发**：用户输入 `lint` 或进行记忆系统体检。
- **行为**：自动扫描 `HOT.md`（热记忆）、`one-context.md`（项目就地）、`one-hippocampus`（全局海马体）与 `one-wiki-v2`（知识库），校验所有三级地图、时间线指针、外部链接的 100% 连通性。
- **结果**：输出断链、孤立卡片或缺失索引的巡检报告并引导修复。

## 3. 业务规则与边界约束

1. **绝对单向隔离**：
   - 机器配置、调试参数、执行流水、私密资产严禁写入人类 Wiki。
   - 人类思考笔记严禁被 AI 自动覆盖或篡改。
2. **消歧第一责任**：当用户省略背景时，AI 必须结合 `HOT.md` 自行消歧；若热记忆无法消歧，坦白提出歧义选项，不擅自瞎猜。
3. **极简操作交互**：回忆与存入过程 AI 自主在后台完成分流与 Git 提交，对话只输出最终结论，不汇报 Git 命令行细节。
