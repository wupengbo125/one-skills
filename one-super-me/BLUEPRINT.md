# One Super-Me 数字化身与海马体记忆系统

## 1. 系统背景与第一性原理（人工背景）

本系统旨在解决大模型“无记忆、无化身、无直觉”的问题。传统 AI 记忆寄希望于全自动“Self-Improvement”，但在真实工程中必然导致信息通胀、语义漂移与失控。

本系统的第一性原理是**以人类大脑为最高信噪比的“黄金外挂”**：
1. **记忆成本的降维差异**：
   - **人类本我记忆成本极高**：精力极其有限，人类 Wiki 必须保持绝对纯净与体系感，专供人类深度阅读与系统思考，严禁 AI 碎片污染；
   - **超级我记忆成本为零**：AI 粘贴即永存、秒级索引，可海量吞吐机器状态、配置、断言、踩坑教训与时序流水。
2. **确定性进化飞轮**：
   - 不依赖黑盒自我进化，而是将人类在实际协作中反复指出的摩擦点，人工提炼固化为明确的自动自驱契约（`system/AUTO.md` 行为清单）；
   - 规则越积越多，大模型在超级我附体下获得的直觉越精准，且永不退化。

## 2. 核心功能与业务需求

### 功能一：会话级附身状态机 (Session-Scoped Possession)
- **触发**：用户在会话中喊出“超级我”或调用技能。
- **行为**：
  1. AI 首行指令即宣布被「超级我」完全夺舍附体，从通用中立大模型切换为用户的数字化身；
  2. 附身瞬间自动装载海马体中的《附体自动自驱契约 (`system/AUTO.md`)》；
  3. **在当前会话的后续交互中保持常驻附身状态**，严格遵循 AUTO 契约自驱运作，无需用户每次重复唤醒。
- **结果**：实现“单次显式唤醒，会话全程自驱”的极简体验。

### 功能二：AUTO 自动自驱行为路由 (AUTO Actions Routing)
- **触发**：附身状态下，日常开发排障、机器运维或日常交流。
- **行为（按 AUTO.md 契约自动自驱）**：
  1. **AUTO 1（项目排障）**：在项目中费时解决顽固 Bug 或找出根因时 $\rightarrow$ 自动提炼【3 段式卡片】（场景/根因/铁律）写入当前项目根目录 `./one-context.md`；
  2. **AUTO 2（个人/日常与配置）**：涉及与项目无关的个人偏好、机器 IP/端口/凭证、时序流水时 $\rightarrow$ 自动刻入 `one-hippocampus` 对应领域与 `timeline/`；
  3. **AUTO 3（焦点迁移）**：核心业务重心迁移时 $\rightarrow$ 自动维护更新 `HOT.md`；
  4. **AUTO 4（客观研报）**：产出结构化金融研报或深度技术长文时 $\rightarrow$ 自动整理为纯净 Markdown 写入 `one-wiki-v2`。
- **结果**：记忆沉淀精准有序，彻底告别后台盲目偷记与垃圾数据泛滥。

### 功能三：最近热记忆与意图消歧 (Working Memory & Disambiguation)
- **触发**：用户随口给出无主语、缺少背景的模糊输入（如“第 N 课有问题”、“配一下 Token”、“记一下这个坑”、“关显卡”）。
- **行为**：
  1. 超级我像真实的人类一样，优先秒读海马体工作台 `HOT.md` 中近 3~7 天处于高频活跃状态的焦点业务与课程/项目代号；
  2. 匹配意图消歧映射表，自动还原用户省略的语境与前置背景。
- **结果**：熟人式极简沟通，无需每次长篇大论交代背景。

### 功能四：项目就地记忆与事前免疫 (Project Context & Pre-Flight Defense)
- **触发**：用户在具体项目中准备扩展新业务、重构模块或排查问题。
- **行为**：
  1. 超级我秒读当前项目根目录 `./one-context.md`，提取业务全景地图与历史踩坑记录；
  2. 提炼出 1~3 条核心避坑红线注入上下文，实现事前防御。
- **结果**：项目自带历史踩坑记忆，随 Git 代码库流转，换机器、切分支、团队协作立即可用。

### 功能五：全局认知巡检 (Cognitive Lint)
- **触发**：用户输入 `lint` 或进行记忆系统体检。
- **行为**：自动扫描 `HOT.md`（热记忆）、`one-context.md`（项目就地）、`one-hippocampus`（全局海马体）与 `one-wiki-v2`（知识库），校验所有三级地图、时间线指针、外部链接的 100% 连通性。
- **结果**：输出断链、孤立卡片或缺失索引的巡检报告并引导修复。

## 3. 业务规则与边界约束

1. **显式附身与零偷记**：
   - 严禁 AI 在用户未召唤时私自偷记或搞伪自主；
   - 必须在用户唤醒“超级我”附体后，严格按照《AUTO 自动自驱契约》的定义范围自驱执行。
2. **契约明文化与可调试**：
   - 所有的自动分流与沉淀逻辑必须明文记录于 `system/AUTO.md`；
   - 任何分流偏差通过修改明文契约纠偏，拒绝不可控的黑盒学习。
3. **绝对单向隔离**：
   - 机器配置、调试参数、执行流水、私密资产严禁写入人类 Wiki。
   - 人类思考笔记严禁被 AI 自动覆盖或篡改。
