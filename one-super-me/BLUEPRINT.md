# One Super-Me 数字化身与海马体记忆系统

## 1. 系统背景与第一性原理（人工背景）

本系统旨在解决大模型“无记忆、无化身、无直觉”的问题。传统 AI 记忆寄希望于全自动“Self-Improvement”，但在真实工程中必然导致信息通胀、语义漂移、偷记乱记与失控。

本系统的第一性原理是**以人类大脑为最高信噪比的“黄金外挂”**：
1. **记忆成本的降维差异**：
   - **人类本我记忆成本极高**：精力极其有限，人类 Wiki 必须保持绝对纯净与体系感，专供人类深度阅读与系统思考，严禁 AI 碎片污染；
   - **超级我记忆成本为零**：AI 粘贴即永存、秒级索引，可海量吞吐机器状态、配置、断言、踩坑教训与时序流水。
2. **Default DROP 防火墙哲学（拒绝伪自主）**：
   - 传统记忆系统的死穴在于“以为自己很聪明在后台偷记”，导致聊天讨论与半成品垃圾污染存储；
   - 本系统采用类似网络防火墙的 **默认全拒绝 (Default DROP)** 机制：纯聊天、讨论、取名、架构推演时，写入权重恒为 0，严禁修改时间线与文件；
   - 唯有命中人类显式指令白名单（“记一下”、“查一下”、“沉淀 context”、“整理成研报”）时，才放行执行。

## 3. 核心功能与业务需求

### 功能一：顶层路由与附身状态机 (Session-Scoped Possession)
- **触发**：用户在会话中呼唤任意化身称谓（“逍遥”、“无双”、“多多”、“超级我”、“super me”）。
- **行为**：
  1. AI 首行指令即宣布被数字化身完全夺舍附体，从通用中立大模型切换为宿主的数字化身；
  2. 附身瞬间自动装载海马体中的《自动自驱契约 (`system/AUTO.md`)》；
  3. **在当前会话的后续交互中保持常驻附身状态**，严格遵循 Default DROP 防火墙白名单运作。

### 功能二：`AUTO.md` 防火墙路由 (Firewall Actions Routing)
- **规则 0（Default DROP）**：讨论、闲聊、推演时，坚决不存、坚决不写；
- **规则 1（显式记录与更新）**：用户指示“记一下/存入海马体/更新记忆” $\rightarrow$ 提取断言写入海马体对应领域地图并登记 `timeline/`；执行更新记忆时（非 link）自动巡检 `HOT.md` 并将 >3 个月条目转移至 `COLD.md`；
- **规则 2（显式查询与消歧）**：用户指示“查一下/想一下/逍遥” $\rightarrow$ 结合 `HOT.md` 消歧后秒级下钻查询海马体卡片；实际命中查入使用时即时刷新 `HOT.md` 对应条目的最近访问时间戳（`YYYY-MM-DD`）；
- **规则 3（显式排障沉淀）**：用户指示“记录 Bug 根因/记入 context” $\rightarrow$ 提炼【3 段式卡片】（场景/根因/铁律）写入当前项目根目录 `./one-context.md`；
- **规则 4（显式研报整理）**：用户指示“整理成长文/写成研报” $\rightarrow$ 整理为纯净 Markdown 写入 `one-wiki-v2`。

### 功能三：热记忆时间戳与冷热生命周期 (Working Memory & Hot/Cold Lifecycle)
- **触发**：用户随口给出无主语、缺少背景的模糊输入，或进行记忆沉淀与更新。
- **行为**：
  1. **意图消歧**：优先秒读海马体工作台 `HOT.md` 中高频活跃焦点业务与课程/项目代号，还原语境；
  2. **活跃刷新**：查询真正命中并查入某条热记忆时，即时刷新 `HOT.md` 中该条目的最近访问时间戳（`YYYY-MM-DD`）；
  3. **惰性淘汰**：执行更新记忆时，自动检查 `HOT.md` 全量时间戳，将超过 3 个月（> 90 天）未被使用的条目自动移入 `COLD.md`（冷记忆归档），保持热工作台高信噪比。

### 功能四：项目就地记忆与事前免疫 (Project Context & Pre-Flight Defense)
- **触发**：用户在具体项目中准备扩展新业务、重构模块或排查问题。
- **行为**：秒读当前项目根目录 `./one-context.md`，提取业务位置与历史踩坑红线，注入前置防御约束。

### 功能五：全局认知巡检 (Cognitive Lint)
- **触发**：用户输入 `lint` 或进行记忆系统体检。
- **行为**：自动扫描 `HOT.md`、`COLD.md`、`one-context.md`、`one-hippocampus` 与 `one-wiki-v2`，校验所有三级地图、时间线指针、外部链接的 100% 连通性。

## 4. 业务规则与边界约束

1. **绝对单向隔离**：
   - 机器配置、调试参数、执行流水、私密资产严禁写入人类 Wiki；
   - 人类思考笔记严禁被 AI 自动覆盖或篡改。
2. **契约明文化与可调试**：
   - 所有的自动分流与沉淀逻辑必须明文记录于 `system/AUTO.md`；
   - 任何分流偏差通过修改明文契约纠偏，拒绝不可控的黑盒学习。
