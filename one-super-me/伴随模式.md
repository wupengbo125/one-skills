# 海马体记忆伴随模式 (Companion Mode)

AI 在任何项目与会话中编码或协作时，全程伴随执行此契约：

## 一、 伴随查 (Read First)
遇到不熟悉的项目代号（如 OneToDo、vfrp）、机器 IP、环境路径、私有服务：
1. **代号速查**：读取 `/home/ctyun/onespace/github/one-hippocampus/system/aliases.md`
2. **全文检索**：终端执行 `super-me search "<关键词>"`（毫秒级 BM25 检索，零 Token 消耗）

## 二、 伴随存 (Write as You Go)
- **宁缺毋滥（铁律）**：日常闲聊、简单问答、琐碎代码修改、未验证方案，**严禁记录**。无硬核增量保持静默。
- **随做随存**：会话中一旦跑通关键配置、解决疑难踩坑、确认资产入口或明确了个人偏好，**在当前轮次顺手落盘**（不依赖会话结束）：
  - 👤 **画像与偏好** $\rightarrow$ 追加至 `/home/ctyun/onespace/github/one-hippocampus/system/profile.md`
  - 🛠️ **操作与排障 (How-to)** $\rightarrow$ 写入 `/home/ctyun/onespace/github/one-hippocampus/memory/methods/<中文主题>.md`
  - 🗺️ **位置与代号 (Where-is)** $\rightarrow$ 写入 `/home/ctyun/onespace/github/one-hippocampus/memory/locations/<中文主题>.md` 或 `system/aliases.md`
  - ⚡ **核心实操流水** $\rightarrow$ 在 `/home/ctyun/onespace/github/one-hippocampus/recent.md` 表格追加一行
- **存后即入库**：写入 Markdown 后立即执行：
  ```bash
  super-me sync "<相对路径>"
  ```
  例如：`super-me sync "memory/methods/本地AI网关接入与模型配置.md"`
