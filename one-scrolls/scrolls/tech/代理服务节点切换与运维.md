# 代理服务节点切换与运维 (Mihomo)

## 1. 核心路径与模式
* **运行目录**：`~/bin/mihomo/`
* **配置源文件**：`$github_dir/dotfiles/tools/mihomo/config.yaml`（修改后同步到 `~/bin/mihomo/config.yaml`）
* **管理脚本**：`$github_dir/dotfiles/tools/mihomo/mihomo.py`（全局软链命令 `mihomo`）
* **网络模式**：TUN 模式（`allow-lan: true`, `enhanced-mode: fake-ip`）

## 2. 常用操作命令
| 命令 | 说明 |
| :--- | :--- |
| `mihomo <数字>` | 直接切换到指定序号节点（秒切，不测速） |
| `mihomo <名称>` | 按名称模糊匹配切换（如 `mihomo 日本`） |
| `mihomo list` | 查看当前所有节点及序号（标出当前连接 `*`） |
| `mihomo auto` | 并发测速并自动切换到最低延迟节点 |
| `mihomo restart` | 重启服务并自动重载配置 |
| `mihomo stop` | 彻底停止进程 |
