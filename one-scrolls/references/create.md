# 封存卷轴手册

卷轴库路径：`scrolls/`

---

## 核心原则

- **分类目录**：按领域分类存放（如 `tech/`、`workflow/`）。
- **全中文命名**：卷轴文件名尽量使用中文（如 `one-scrolls/scrolls/tech/某软件本地安装终极避坑手册.md`）。
- **卷轴本质**：提炼实操方法（怎么做）、资源定位（在哪里）、关键避坑事实。

---

## 执行步骤

0. **查找已有卷轴**：
   优先找出已知的卷轴，往里面继续写，找不到再新建
1. **归档落盘**：
   - 写入 `scrolls/<英文分类>/<中文主题>.md`；
   - 若存在同名卷轴则章节追加，不存在则新建。
2. **更新大纲**：
   - 在 `scrolls/index.md` 追加卷轴指针与核心解决要点（= 描述）。
3. **增量同步索引**：
   ```bash
   python3 scripts/scrolls.py sync "<英文分类>/<中文主题>.md"
   ```
4. **提交 Git**：
   - 在本技能所在仓库执行本地 commit 并 push。
5. **极简反馈**：一句话仅反馈写入路径与标题。以及推送状态
