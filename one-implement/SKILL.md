# 极简实现流程 (One Implement)

核心原则：平铺计划、最小化实现、严防多改。能简单就不要多写。

---

## 流程

### 1. 平铺计划（动手前）
列出一行一行的平铺 plan（严禁嵌套复杂大纲），明确每步具体改动。向用户确认后开工。

### 2. 最小化最简单实现
- 严格以需求为边界，只改需求相关内容。
- 绝不顺手重构，绝不添加多余抽象，绝不改无关文件。

能简单就不要多写，以最小代码量达成目标。

###3. 优雅实现

发挥你所有的知识，弄最好的架构设计、最优雅的实现、最简洁的代码风格、最高效的算法和数据结构、最完美的设计模式。

### 4. 等号审查
对照用户原始需求与 `git diff HEAD`：
- 改多了？（有无未要求的改动、多余抽象）
- 改少了？（需求是否遗漏）
- 改偏了？（是否符合预期）

改动必须与需求严格画等号。
