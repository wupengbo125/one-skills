# Update Notes (更新已有文档)

本 Skill 专门负责在个人知识库（`$one_llmwiki_dir`，默认 `~/onespace/github/one-llmwiki/`）中定位已有的相关文档，并根据用户提供的新经验、修复方案或补充信息进行更新。

> **区别说明**：
> - 新建笔记/存资料请使用 `one-take-notes`（新建日期文件存入 `raw/`）。
> - 本 Skill 仅处理**对已有旧文档的定位、补充与修正**。

---

## 运行规则与步骤

### 1. 前置拉取与检索定位
1. 进入知识库目录（`$one_llmwiki_dir` 或 `~/onespace/github/one-llmwiki`），执行 `git pull` 保证最新。
2. 根据用户要更新的主题关键词，在知识库（`raw/` 和 `onewiki/`）中检索最匹配的已有文档。

### 2. 冲突与多文档抉择
如果检索出多篇相关文档：
- **优先自主判断**：结合当前对话上下文、关键词权重、文档修改时间与内容深度，优先自行筛选出最合适的一篇目标文档。
- **强歧义再询问**：若多篇文档权重相当、确实无法自行决断，列出候选文档路径与简短说明，请用户指定。

### 3. 拟定方案并等待用户确认
**在未获得用户确认前，严禁直接落盘修改文档。**
向用户明确呈现：
- **目标文档路径**：如 `raw/technology/2026-08-23-tailscale-ssh.md`（若关联 summary/concept 一并列出）。
- **拟更新的具体内容**：清晰展示拟追加的章节、修改的内容或参数说明。
- 提示用户确认。

### 4. 确认后写入与 Git 同步
用户确认后：
1. 使用精准编辑工具将内容更新/追加至目标文档。
2. 提交并同步 Git：
   ```bash
   git add -A && git commit -m "docs(update): <简要描述>" && git push
   ```
3. 极简反馈完成状态与更新的文件路径。
