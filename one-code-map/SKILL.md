# Code Map (代码地图管理)

轻量级代码库结构地图 (`MAP.md`) 管理技能。保持极致简单，拒绝任何复杂机制。

---

## 自动路由与执行逻辑

调用 `one-code-map` 时自动识别项目状态：

1. **未建立 `MAP.md` (初始化 `init`)**：
   - 读取本目录下的 `MAP-TEMPLATE.md` 模板。
   - 扫盘当前物理代码结构，在根目录及关键子目录下生成 `MAP.md`（包含核心模块索引、相对文件链接与 Mermaid 模块依赖流向图）。

2. **已存在 `MAP.md` (对照更新 `update`)**：
   - 拿当前最新的代码结构直接对比现有 `MAP.md`：
     - **结构一致**：提示结构无变动，直接完成。
     - **存在差异**：直接修正受影响子目录与根目录的 `MAP.md` 模块索引、相对链接与 Mermaid 模块依赖流向图。

3. **映射检查 (`lint`)**：
   - 检查并修复所有 `MAP.md` 中的相对链接指针。
