# one-audit-plan

## 干什么

直接读取指定路径的平铺计划文档，将其中记录的每次用户确认的平铺计划（V1 到 VN）进行融合总结，提炼成一份覆盖式的全量真实需求，并全量覆盖回写该文档（清空中间的 V1~VN 历史版本）。

## 步骤

1. 读取提示词指定的平铺计划文档（若有 `起点提交：<id>` 则保留在文件顶部）。
2. 将文档中记录的各版本平铺计划（V1~VN）提炼融合，去除已废弃或被覆盖项，整理为最终真实需求。
3. 全量覆盖回写平铺计划文档（清空 V1~VN 各版本记录）：

   ```markdown
   起点提交：<commit-id>（若有）

   # 需求清单

   ## 要做什么
   - 需求点 1
   - 需求点 2
   ```

## 规范

- **真理之源**：需求必须且只能来自于平铺计划文档中已记录的平铺计划，严禁自行脑补。
- **覆盖回写**：最终文档只保留全量真需求，不保留 V1~VN 中间演进版本。
