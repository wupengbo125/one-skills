# Faithful Implement

根据用户指定的当前会话、需求文档或直接指令，进行全新的代码/功能实施（从 0 到 1 落地）。

## 核心原则

1. **精准忠实交付**：
   - 完整实现全部需求，绝不增加任何需求范围之外的额外功能、配置或盲目预留接口。
   - 如遇需求模糊或存在歧义，先询问用户明确意图，绝不自作主张。

2. **极简代码原则**：
   - 用最少、最清晰的代码解决问题，拒绝任何投机性、预测性的过度设计。
   - 能用现成库不造轮子，能用简单函数不做复杂抽象。

3. **测试驱动与质量验证**：
   - 尽可能使用 `/tdd` 编写测试，确保测试完全覆盖各项需求点与边界条件。
   - 实施过程中定期运行类型检查与测试套件。

4. **审查与提交**：
   - 实施完成后运行 `/code-review` 审查，只修复与本次需求直接相关的问题。
   - 确认全部需求实现且测试通过后提交到当前分支。
